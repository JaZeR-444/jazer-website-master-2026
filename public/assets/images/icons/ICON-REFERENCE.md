## 🎨 Icon Styling Guide

### CSS Integration

All icons use `currentColor`, making them easy to theme:

```css
/* Match text color */
.icon {
  color: #00f2ea; /* JaZeR cyan */
}

/* Icon inherits color */
img.icon {
  width: 24px;
  height: 24px;
  filter: brightness(0) saturate(100%) invert(1); /* For coloring */
}

/* Better approach - use inline SVG for color control */
svg {
  width: 24px;
  height: 24px;
  stroke: currentColor;
  fill: currentColor;
}
```

### Theming with CSS Variables

```css
:root {
  --icon-color: #00f2ea;
  --icon-size: 24px;
}

.icon {
  width: var(--icon-size);
  height: var(--icon-size);
  color: var(--icon-color);
}
```

### Animation Examples

```css
/* Hover effect */
.icon:hover {
  transform: scale(1.1);
  transition: transform 0.2s ease;
}

/* Pulse animation */
@keyframes pulse {
  0%,
  100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.15);
  }
}

.icon-pulse {
  animation: pulse 2s infinite;
}

/* Spin (for loading states) */
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}

.icon-spin {
  animation: spin 1s linear infinite;
}
```

## 🚀 Usage Best Practices

### 1. **Accessibility**

Always include alt text or aria-labels:

```html
<!-- Decorative icon (no alt needed) -->
<img src="icon.svg" alt="" aria-hidden="true" />

<!-- Functional icon (needs description) -->
<button aria-label="Play music">
  <img src="play.svg" alt="" />
</button>
```

### 2. **Performance**

- Use SVG format (already optimized)
- Consider sprite sheets for many icons
- Lazy load icons below the fold

### 3. **Consistency**

- Use 24x24 base size
- Maintain stroke-width of 1.5
- Use `currentColor` for theming

### 4. **Responsive Sizing**

```css
/* Mobile */
.icon {
  width: 20px;
  height: 20px;
}

/* Tablet+ */
@media (min-width: 768px) {
  .icon {
    width: 24px;
    height: 24px;
  }
}

/* Large UI elements */
.icon-lg {
  width: 32px;
  height: 32px;
}
.icon-xl {
  width: 48px;
  height: 48px;
}
```
