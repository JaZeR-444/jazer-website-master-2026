## 🎯 Design Strategy

### Visual Hierarchy
1. **Strategic Scaling**: Logos are sized (24px to 600px) based on the importance of the section.
2. **Contextual Variety**: Alternating between the Wordmark (Bubble) and Icon (Monogram) to prevent visual fatigue.
3. **Consistency**: All assets use the `/public/assets/images/` root path for reliable rendering across all platforms.
